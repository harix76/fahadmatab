# Fahad Matab — fahadmatab.pk

Official herbal oil storefront for **Hakeem Azhar** (`fahadmatab.pk`), built with React, Vite, and Tailwind CSS using the **Montserrat** & **Roboto** typography pair and the deep botanical green (`#102212` / `#173A21`) + herbal gold (`#FFB700` / `#EFC368`) + cream (`#F8F4E8`) color system.

## Products & Flow
- **Shahi Quwwat Male Vitality Herbal Oil** (`60ml` & `120ml` amber glass dropper bottle)
- **Zulf-e-Hayat Women's Herbal Hair Oil** (`120ml` & `240ml` emerald glass dispenser bottle)
- **1 + 1 Dual Care Bundle**
- **Direct WhatsApp Checkout:** Every product button and the 3-step Quick Order card routes customers directly to `https://wa.me/...` with a pre-filled order/consultation message.
- **Anonymous Verified Reviews:** Coded buyer IDs (`#FM-408`, `#FM-519`, etc.) with filter tabs and privacy assurances.
